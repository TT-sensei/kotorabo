# 出題エンジン仕様 v1.0

## 今日の研究5問

1. `recall`：以前触れた内容を思い出す
2. `retry`：最近迷ったSKILLを別問題で確かめる
3. `current`：未着手または現在の内容
4. `stretch`：今より少し深い内容
5. `transfer`：同じ考え方を違う題材で使う

3問は retry/current/transfer、10問は5役割を複数回含む。同じ日・同じ履歴なら並びを安定させ、直近5問はできるだけ避ける。

## 誤答後

1. 最初の誤答を履歴に残す
2. その場で一度考え直せる
3. ヒントは任意
4. 同じSKILLの別問題を約2問後に追加
5. 最終回答だけでなく迷いも習熟判定に使う

## 暫定的な習熟集計

ヒントなしの `best` で成功した最大DEPTHを中心にする。直近4回答の半数以上が誤答・○・ヒント使用・再回答なら、次の研究へ優先して入れる。

問題数と利用データが増えたら、同一問題反復の重み、転移成功の重み、問題難易度の実測補正、長期間空いた内容の再確認を検討する。

# 出題エンジン仕様 v1.0

## 今日の研究5問

1. `recall`：以前触れた内容を思い出す
2. `retry`：最近迷ったSKILLを別問題で確かめる
3. `current`：未着手または現在の内容
4. `stretch`：今より少し深い内容
5. `transfer`：同じ考え方を違う題材で使う

3問は retry/current/transfer、10問は5役割を複数回含む。同じ日・同じ履歴なら並びを安定させ、直近5問はできるだけ避ける。

## 学年とチャレンジレベル

- `profile.grade`：学校での学年。プロフィール表示に使う。
- `profile.challengeLevel`：現在取り組みたい難しさ。通常出題の候補抽出に使う。
- 初回は2つを同じ値にするが、その後は別々に変更できる。
- レベル変更では学習履歴を消さない。
- 古い保存データに `challengeLevel` がなければ、保存済みの `grade` を初期値として引き継ぐ。

通常出題では `gradeMin <= challengeLevel` かつ `contentLevel <= challengeLevel + 1` を候補にする。`stretch` で一段上を含めるため、現在地より少し先にも進める。

## 特訓モード

1. 子どもがLABとSKILLを選ぶ。
2. 選択SKILLの問題を最優先する。
3. 最近の迷い、未着手、チャレンジレベルへの近さ、直近出題の回避で並べる。
4. 問題数が足りない場合は、同じLABの近い問題で補う。
5. 選択SKILLについては学年・チャレンジレベルの上下を制限しない。

特訓は3問または5問。現在の問題数でも全SKILLについて重複なしで編成できる範囲に固定している。問題データ拡充後は10問コースを追加できる。

## 誤答後

1. 最初の誤答を履歴に残す
2. その場で一度考え直せる
3. ヒントは任意
4. 同じSKILLの別問題を約2問後に追加
5. 最終回答だけでなく迷いも習熟判定に使う

## 暫定的な習熟集計

ヒントなしの `best` で成功した最大DEPTHを中心にする。直近4回答の半数以上が誤答・○・ヒント使用・再回答なら、次の研究へ優先して入れる。

問題数と利用データが増えたら、同一問題反復の重み、転移成功の重み、問題難易度の実測補正、長期間空いた内容の再確認を検討する。

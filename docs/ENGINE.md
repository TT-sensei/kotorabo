# 出題エンジン仕様 v2.0

## 今日のことばチャレンジ

3問・5問・10問から選び、6ジャンルを横断して出題します。

- `recall`：以前に取り組んだ内容を思い出す
- `retry`：最近迷ったジャンルを別問題で確かめる
- `current`：未着手または現在の内容
- `stretch`：チャレンジレベルより少し上に進む
- `transfer`：同じ言葉の見方を別の文脈で試す

同じセッション内で問題IDを重複させず、直近に解いた問題をできるだけ避けます。

## ジャンル別特訓

1. 6ジャンルから一つを選ぶ
2. 選んだジャンルの問題を中心に編成する
3. 最近の迷い、未着手、チャレンジレベル、直近出題の回避を考慮する
4. 3問または5問に取り組む

## 誤答後

1. 最初の回答を履歴に残す
2. その場で一度考え直せる
3. ヒントは任意
4. 同じジャンルの別問題を少し後に追加する
5. 最終回答だけでなく、ヒント利用や考え直しも記録する

## 言葉ごとの学習段階

ことばファイルは、問題で実際に出会った語句を集めます。同じ語句に複数の問題IDがひも付く場合は、一つのカードにまとめます。

- 0：まだ出会っていない
- 1：出会った
- 2：意味が分かる（正答または許容できる答え）
- 3：使い分けられる（ヒントなしでbest）
- 4：別の場面でも使える（transfer問題でbest、または複数回のヒントなしbest）

語句ごとの記録と、ジャンルごとのSKILL習熟を併用します。ジャンルの習熟度だけで語彙の定着を判断しません。

## 学年とチャレンジレベル

- `profile.grade`：学校の学年。表示に使う。
- `profile.challengeLevel`：通常出題の難しさ。
- 初回は同じ値にするが、その後は別々に変更できる。
- レベル変更では語彙の学習履歴を消さない。
- 旧版の履歴は、現在の問題バンクに存在する問題IDだけ引き継ぐ。文法・接続詞・文章問題の履歴は語彙カルテへ混ぜない。

## 習熟判定

ヒントなしの `best` で成功した最大DEPTHを中心にする。直近の回答で誤答・許容回答・ヒント使用・考え直しが続く場合は、次のチャレンジで再確認を優先します。

語彙カードの段階とジャンルの習熟表示は、異なる目的の指標として扱います。

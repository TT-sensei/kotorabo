# 問題データ仕様 v2.1

ことラボは語彙学習に特化します。問題は `js/data/question-sets/` に置き、`js/data/questions.js` で統合します。

## 有効な問題ファイル

| ファイル | 内容 |
|---|---|
| `words.js` | 基本語彙、意味、類義語、対義語、場面に合う語 |
| `systematic-language.js` | 学年段階を意識した意味・仲間、気持ち、学習語彙、言葉の成り立ち |
| `compound-structure.js` | 二字熟語の構成 |
| `vocabulary-expansion.js` | 6ジャンルに追加した独自語彙60問 |
| `language-use.js` | 文脈に合わせて言葉を選ぶ独自問題12問 |
| `municipal-vocabulary.js` | 教科横断の文脈を使った独自語彙126問 |
| `early-vocabulary.js` | L1・L2を中心にした入門語彙36問（6ジャンル各6問） |

旧版の `sentence.js`、`connection.js`、`passage.js`、`connectives-extra.js` は、現在の問題バンクに読み込みません。ことわざ・慣用句・故事成語は専用アプリ「ことばのしるべ」に集約し、ことラボの有効な問題バンクには含めません。

## 現行バンクの実測と改善課題

2026-11-11時点の有効な324問を集計した値です。問題を追加・修正した場合はテストと合わせて更新します。

- ジャンル別：意味・仲間60、成り立ち63、気持ち54、学習51、感覚49、ぴったり47
- 内容レベル別：L1=23、L2=36、L3=30、L4=58、L5=125、L6=52
- ことばファイル：既存239語に追加語句を統合（同じジャンル・同じ語句は一枚に集約）
- acceptable（意味は合うが最適ではない）を含む問題：66問

今回、各ジャンルに入門語彙を6問ずつ追加し、L1・L2を合計59問に増やしました。それでも現状はL5・L6に問題が集中し、低い内容レベルの語彙をさらに増やす余地があります。特に教科横断セットはL4〜L6が中心です。したがって、現行バンクを「小学1〜6年の語彙を均等に網羅したもの」とは扱いません。今後は、教科書語彙リスト等を照合しながら、低学年の生活語彙・身近な語彙を優先して補います。

各ジャンルの最も低いcontentLevelにある問題数も均等ではありません。初期段階の問題数は、入門語彙追加後で意味・仲間9、ぴったり8、気持ち3、感覚5、学習・思考6、成り立ち4です。このため、以前の特訓ロジックでは初期レベルの問題だけに絞ると、気持ちジャンルが1問で終わるなど、3問・5問の指定数に届かない場合がありました。現在の出題エンジンでは、同じジャンル内の近い上位レベルからも補い、指定問題数を確保するように修正しています。contentLevelは語彙・課題の難しさであり、教科書で初出する学年や発達段階と同一ではありません。現行データでは誤った学年表示を避けるためgradeMinを持たせず、ことばファイルには内容レベルを表示します。将来、学年情報を追加する場合は、教科書語彙リストとの照合結果と実際の使用場面を別々に確認し、根拠を記録します。

## 6つのジャンルID

| ID | 内容 |
|---|---|
| `meaning` | ことばの意味・仲間 |
| `precise` | ぴったりのことば |
| `feelings` | 気持ち・人がら |
| `sensory` | 動き・様子・感覚 |
| `learning` | 学習・思考のことば |
| `structure` | ことばの成り立ち・熟語の構成 |

問題データの `lab` は上記ID、`skill` は `vocab.<ジャンルID>` とします。

## 主な項目

| 項目 | 意味 | 注意 |
|---|---|---|
| `id` | 履歴保存用の固有ID | 公開後は変更しない |
| `version` | 問題内容の版 | 文面・正解基準変更時に上げる |
| `lab` | 6ジャンルのいずれか | 上記IDから選ぶ |
| `skill` | スキルID | `vocab.<lab>` を使用 |
| `subskill` | 一問の焦点 | 一問一焦点にする |
| `contentLevel` | 内容の難しさ | 1〜6。学年とは別 |
| `depth` | 学習の深さ | D1〜D6 |
| `purpose` | 主な用途 | diagnostic/practice/transfer |
| `thinkingTags` | 思考・語彙のタグ | 類題や分類に利用 |
| `crossTags` | 横断タグ | 場面、目的、程度など |
| `vocabularyTerm` | ことばファイルに登録する語句 | 熟語など、正解の選択肢が語句でない場合に指定 |
| `vocabularyMeaning` | 語句の意味・構成の説明 | 必要に応じて指定 |
| `vocabularyExample` | 語句を使った例 | 必要に応じて指定 |
| `context` | 問題の場面・文脈 | 文脈なしで成立する問いは省略可 |
| `options` | 選択肢 | `best/acceptable/incorrect` を設定 |
| `hint` | 小さな手がかり | 正解をそのまま言わない |
| `explanation` | 考え方・正答根拠 | 選択の理由を短く説明する |

## 判定

- `best`：意味と文脈の両方に最も合う
- `acceptable`：意味は成り立つが、場面や伝わる内容の点で最適ではない
- `incorrect`：意味・文脈・語の関係に合わない

`acceptable` を設定する場合は、「意味は合うが、なぜbestではないか」を選択肢のフィードバックに明記します。単なる言い回しの好みで差を付けません。

## 熟語の構成

「ことばの成り立ち」では、必要に応じて次の関係を扱います。

1. 似た意味の漢字を組み合わせる
2. 反対の意味の漢字を組み合わせる
3. 上の漢字が下の漢字を詳しくする
4. 下の漢字が上の漢字の目的・対象を表す
5. 上が主語、下が述語になる
6. 上の漢字が下の漢字の意味を打ち消す

熟語は一字ずつ訓読みにして意味を確かめ、なぜその構成になるかを説明できる問題にします。

## 追加前の確認

1. 語彙そのものを学ぶ問題か。文法・文章構成の問題になっていないか。
2. 一問で複数の能力を同時に測っていないか。
3. 文脈だけで正答の根拠が分かるか。
4. 似た選択肢に、意味の違いがあるか。
5. 誤答の原因をヒントと解説で扱えるか。
6. 同じ語句を別の問題・別の場面で確かめられるか。
7. 漢字や背景知識だけで語彙力を誤判定しないか。

## 語彙を育てる観点

語彙を扱うときは、次の三つの場面を意識します。これは学習内容を整理するための本アプリ独自の編集方針です。

- 言葉の宝箱：気持ち・人がら・動き・様子などを、より細やかに表す。
- 伝え合い：意見や理由を、相手に伝わる言葉で表す。
- 学習で使う言葉：比べる・調べる・まとめるなど、教科の学習で必要な語を使う。

「言葉を知る→意味や違いを比べる→場面に合う言葉を選ぶ→別の場面でも使う」という流れを大切にします。ことばの成り立ちは、独立した学習領域として扱います。

## 教科横断語彙を追加するときの方針

- 教科の知識を問うのではなく、学習場面で使われる語の意味を問う。
- 語句の難しさだけでなく、学年段階と教科での使用場面を確認する。
- 「原因・結果」「仮説・検証」「分析・考察」のように、混同しやすい語は意味の違いを明確にする。
- 同じ語を複数の場面で使い、別の文脈でも意味が保たれるか確かめる。
- 公開語彙リストや教育委員会の教材は、語彙領域・学習機会を点検するために参照し、語句一覧・問題文・例文・選択肢・解説は転記しない。

## 独自教材データの条件

- 市販教材に掲載された語句一覧を入力データとして転記しない。
- 市販教材固有の分類名、選定順、例文、解説、問題文を再現しない。
- 語句、場面、選択肢、フィードバックを独自に設計する。
- 参考資料に依存しなくても、問題の正答根拠をこのリポジトリ内で説明できる状態にする。
- ことばファイルには、問題で実際に出会った語句だけを登録する。

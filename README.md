# ことラボ

言葉を知る。意味を比べる。使いこなす。

小学1〜6年生を対象に、語彙を増やし、場面に合う言葉を選べるようにする国語学習アプリです。文法や文章構成を広く扱うのではなく、言葉そのものの意味・違い・成り立ちに集中します。

ことわざ・慣用句・故事成語は、専用アプリ「ことばのしるべ」で学びます。ことラボでは重複して扱わず、日常生活や教科学習で使える幅広い語彙を増やします。

## ことラボで学ぶ6つのジャンル

| ジャンル | 学習すること |
|---|---|
| ことばの意味・仲間 | 言葉の意味、類義語、対義語、仲間分け、抽象的な語の理解 |
| ぴったりのことば | 似た言葉の意味やニュアンス、場面に合う語の選択 |
| 気持ち・人がら | 心情、性格、人への接し方を表す言葉 |
| 動き・様子・感覚 | 動作、音、状態、感覚を具体的に表す言葉 |
| 学習・思考のことば | 観点、仮説、検証、要因、傾向など、調べたり考えたりするときに使う言葉 |
| ことばの成り立ち・熟語の構成 | 接頭語・接尾語・複合語、二字熟語の構成 |

「接続詞」「敬語」「主語・述語」「文の組み立て」「文章構成」など、文法や文章の仕組みを学ぶ問題は、ことラボの出題対象に含めません。

## 学習の流れ

1. 新しい言葉に出会う
2. 意味を確かめる
3. 似た言葉と比べる
4. 文脈に合う言葉を選ぶ
5. 別の場面でも使えるか確かめる

「今日のチャレンジ」は3問・5問・10問から選べます。「テーマ別に特訓する」では、6ジャンルから選んで3問・5問に取り組めます。誤答した言葉や力は、同じ内容の別問題で改めて確かめます。

## 主な機能

- 学年とチャレンジレベルを別々に設定
- 6ジャンルから出題する今日のチャレンジ
- 場面に合わせて言葉を選ぶ「使ってみる」問題
- ジャンル別の特訓モード
- 「◎ 一番ぴったり／○ 合っている／↺ もう一度」の段階判定
- ヒント、選択肢ごとのフィードバック、考え方の解説
- 誤答後の考え直しと、同じジャンルの別問題による再確認
- 問題で実際に出会った言葉を集める「ことばファイル」
- 言葉ごとの学習段階（出会った／意味が分かる／使い分けられる／別の場面でも使える）
- 挑戦・考え直し・継続・6ジャンルの成長を記録する達成バッジ
- ナビキャラクター、研究XP、研究者レベル
- `localStorage` による端末内保存

## 現在の問題データ

有効な問題バンクは162問です。

- 基本の語彙問題：30問
- 学年段階を意識した語彙：48問
- 熟語の構成：12問
- 追加語彙セット：60問
- 文脈の中で語彙を使う練習：12問
- ことばファイルの登録語句：問題で出会った語句を自動集約（重複は一つに整理）

問題で扱う語句・意味・用例・フィードバックは独自に作成しています。学習領域や発達段階を検討する際に公開資料を参考にすることはありますが、市販教材の語句一覧・配列・例文・解説を転記しません。公開資料は語彙を捉える観点の参考にとどめ、問題・場面・選択肢・解説は独自に作成します。

## 旧問題ファイルについて

`sentence.js`、`connection.js`、`passage.js`、`connectives-extra.js` は、今回の語彙特化版の問題バンクから外しています。ことわざ・慣用句・故事成語も専用アプリ「ことばのしるべ」に集約し、ことラボでは読み込みません。

## 動作確認

`npm test`

`npm run serve`

サーバー、API、外部データベース、APIキー、外部フォント、外部音源は使いません。GitHub Pagesでそのまま公開できます。

学習履歴と設定はブラウザ内に保存します。学校の学年とチャレンジレベルを変更しても、語彙の学習履歴は維持されます。旧版の履歴は、現行の語彙問題IDと一致するものだけを引き継ぎます。

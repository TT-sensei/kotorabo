# ことラボ

ことばをためす。文をつくる。伝える力が育つ。

小学1〜6年生が、同じ4つのLABで「ことば → 文 → 文と文 → 文章」と力を広げる国語トレーニングアプリです。

## 現在の動作版

- 学年・読み方サポートの初回設定
- 学校の学年とは別に、いつでも変えられるチャレンジレベル
- 4LABのスタート診断
- 「今日の研究」3問・5問・10問
- SKILLを選んで3問・5問に取り組む特訓モード
- 思い出す／苦手をもう一度／今の力／一歩先／別場面を混ぜる出題
- `◎ 一番ぴったり／○ 合っている／↺ もう一度` の段階判定
- ヒント、任意の解説、誤答したSKILLの遅延類題
- 自由記述の出口「ためしてみよう」
- 子ども向け研究カルテ
- `localStorage` による端末内保存

## 編集する場所

| 変更したいもの | ファイル |
|---|---|
| 問題文・選択肢・ヒント・解説 | `js/data/questions.js` |
| スキル名・LABとの対応 | `js/data/skill-map.js` |
| 出題の組み合わせ | `js/core/engine.js` |
| 保存方法 | `js/core/storage.js` |
| 画面と操作 | `js/app.js` |
| 見た目 | `css/style.css` |

問題を追加・調整するときは、先に [問題データ仕様](docs/QUESTION_DATA.md) を確認してください。

## 動作確認

```bash
npm test
npm run serve
```

サーバー、API、外部データベース、APIキー、外部フォント、外部音源は使っていません。GitHub Pagesでそのまま公開できます。

学習履歴と設定は一人一台端末を前提にブラウザ内へ保存します。学校の学年を変えたり、チャレンジレベルを上げ下げしたりしても、これまでの学習履歴は残ります。

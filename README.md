# ことラボ

**言葉を知る。意味を比べる。使いこなす。**

ことラボは、小学生が語彙を増やし、言葉の意味やニュアンスを理解し、場面に合う言葉を選んで使えるようになることを目指す、語彙学習アプリです。

学年を選ばずに始められ、ジャンルごとの学習履歴に応じて出題の難しさを調整します。単に言葉の意味を暗記するのではなく、似た言葉と比べたり、文脈に合う言葉を選んだり、別の場面で使えるか確かめたりする学習を大切にしています。

- 公開版：https://tt-sensei.github.io/kotorabo/
- リポジトリ：https://github.com/TT-sensei/kotorabo

## ことラボの学習方針

ことラボでは、語彙を「知っている」だけで終わらせず、「意味が分かる」「違いを説明できる」「場面に合わせて使える」ことを目指します。

学習の基本的な流れは次のとおりです。

1. 新しい言葉に出会う
2. 言葉の意味を確かめる
3. 似た言葉や反対の言葉と比べる
4. 文脈に合う言葉を選ぶ
5. 別の場面でも使えるか確かめる
6. 必要に応じて、学びノートに自分の言葉で記録する

ことわざ・慣用句・故事成語は、専用アプリ「ことばのしるべ」で扱います。ことラボでは重複を避け、日常生活や教科学習で使う幅広い語彙に集中します。

## 6つの学習ジャンル

| ジャンル | 学習すること |
|---|---|
| ことばの意味・仲間 | 言葉の意味、類義語、対義語、仲間分け、抽象的な語 |
| ぴったりのことば | 似た言葉の意味やニュアンス、場面に合う語の選択 |
| 気持ち・人がら | 心情、性格、人への接し方を表す言葉 |
| 動き・様子・感覚 | 動作、音、状態、感覚を具体的に表す言葉 |
| 学習・思考のことば | 観点、仮説、検証、要因、傾向など、調べたり考えたりするときに使う言葉 |
| ことばの成り立ち・熟語の構成 | 接頭語・接尾語・複合語、二字熟語の構成 |

接続詞、敬語、主語・述語、文の組み立て、文章構成など、文法や文章の仕組みを中心に学ぶ問題は、現在のことラボの出題対象に含めません。

## 学習の仕組み

### 今日のことばに挑戦

ホーム画面から、学年や問題数を選ばずに5問のチャレンジを始められます。6ジャンルの学習履歴や、復習が必要な領域などを考慮して問題を組み合わせます。

### ジャンル別の自動難易度調整

難易度は学年で固定せず、ジャンルごとの問題レベルと学習履歴から調整します。

- 初回は、そのジャンルに用意された最もやさしい問題段階から始める
- ヒントなしの正答が続くと、段階的にレベルを上げる
- つまずきが続くと、直近の安定した段階を基準に一段階下げて確かめる
- ジャンルごとに用意された問題の最低・最高レベルを超えない
- 最近取り組んだ問題が続けて出にくいようにする

### 特訓と振り返り

気になるジャンルを選んで取り組む特訓モードがあります。正誤だけでなく、「一番ぴったり」「合っている」「もう一度」の段階で答えを振り返り、選択肢ごとのフィードバックや解説で考え方を確かめます。

### ことばファイル・学びノート

問題で実際に出会った言葉を「ことばファイル」に集めます。言葉ごとに、意味・例文・関連する言葉などを確認できます。

「学びノート」では、次の内容を自分の言葉で記録できます。

- 自分の言葉で意味を書く
- 自分で例文を作る
- 気づいたことや、似た言葉との違いを書く

### 成長の記録

挑戦や考え直し、継続、6ジャンルでの学習状況を記録します。達成バッジや研究XP・研究者レベルは、学習の積み重ねを見えるようにするための仕組みです。

教科横断の問題では、教科の知識そのものを問うのではなく、学習場面で使われる言葉の意味や使い方を問います。たとえば、原因・結果・影響・条件・仮説・検証・分析・考察など、学習や思考を支える語彙を扱います。

問題で扱う語句・場面・選択肢・用例・フィードバックは、ことラボ用に独自に作成しています。2026年11月11日時点で、ジャンル別は意味・仲間60、成り立ち63、気持ち54、学習51、感覚49、ぴったり47です。内容レベル別ではL1=23、L2=36、L3=30、L4=58、L5=125、L6=52です。ことばファイルには追加語句も登録し、同じジャンルの同じ語句は一枚にまとめます。入門語彙36問を追加しましたが、L5・L6にも引き続き多くの問題があり、低い内容レベルの語彙は今後も優先して補います。小学1〜2年向けの生活語彙はまだ十分ではなく、今後の優先的な拡充領域です。問題数や内訳を変更した場合は、この表とテスト内の件数チェックも更新してください。

### 参考資料の利用と著作権への配慮

参考資料は、語彙領域や学習機会、語彙指導の考え方を点検するために利用します。公開資料・市販教材に掲載された問題文、例文、選択肢、解説、語句一覧の配列などを、そのまま転記・転載・再現することはしません。

- 語彙を選ぶ際は、複数の資料や実際の学習場面を照らし合わせる
- 問題の場面、問い方、選択肢、解説は独自に設計する
- 参考資料の分類や配列を、そのままアプリの構成として複製しない
- 画像・イラスト・キャラクター等は、利用条件を確認した素材のみを使う

※参考資料の掲載は、個々の資料や素材の利用許諾を意味するものではありません。利用前に各サイト・資料の利用条件を確認してください。

## 開発・動作環境

ことラボは、ブラウザ上で動く静的なHTML・CSS・JavaScriptアプリです。

- APIキー、外部API、バックエンド、外部データベースは使用しない
- 学習履歴、設定、学びノートはブラウザの `localStorage` に保存する
- アカウント登録は不要
- GitHub Pagesで公開できる構成
- 外部フォントや外部音源など、不要な外部依存を増やさない

### ローカルでの確認

Node.jsが利用できる環境で、リポジトリのルートから実行します。

- テスト：`npm test`
- ローカルサーバー：`npm run serve`

`npm run serve` を実行したら、ブラウザで `http://localhost:4173` を開きます。

## 問題を追加するときのチェック

1. 語彙そのものの意味や使い方を学ぶ問題になっているか。
2. 一問で複数の能力を同時に測ろうとしていないか。
3. 文脈から正答の根拠を説明できるか。
4. 選択肢の意味が重なりすぎていないか。
5. 「合っているが一番ではない」選択肢を使う場合、その理由を説明できるか。
6. ヒントが正解をそのまま示していないか。
7. 解説が正答の理由と誤答の見直しにつながっているか。
8. 同じ語句を別の文脈でも確かめられるか。
9. 漢字の読みや背景知識だけで、語彙力を誤判定しないか。
10. 問題IDを既存の学習履歴と整合するように管理しているか。
